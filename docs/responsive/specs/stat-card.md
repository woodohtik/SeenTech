## مواصفة: StatCard (بطاقات الأرقام والإجراءات)

**الملف:** `src/components/ui/StatCard.tsx` (ومعه `StatIcon` و`StatBadge`). `DashboardGridCard.tsx` مبني عليه.

### لماذا
| في البطاقة القديمة | المشكلة | في الجديدة |
|---|---|---|
| التسمية `text-xs uppercase tracking-widest` | 12px، وتباعد حروف على العربي (DESIGN.md §2 يمنعه) | 16px، كما هي، سطران كحد أقصى (`line-clamp-2`) |
| الرقم `text-2xl sm:text-3xl` | حجم ثابت؛ في عمود ضيق خرج «4,140.00» من البطاقة | Tajawal 700، `clamp(22px, 11cqi, 28px)` بعرض **البطاقة**، لا يلتف |
| لا `min-w-0` | المحتوى يدفع البطاقة لتتجاوز عمودها | كل صف `min-w-0` |
| زاوية 16/24 وظل | DESIGN.md §4 و§5: البطاقة 12 وحد 1px بلا ظل | `rounded-[12px] border` بلا ظل |

### البنية
```
┌──────────────────────────────┐
│ [أيقونة 48]          [شارة] │  mb 16
│                              │
│ التسمية (16، سطران)          │
│ الرقم (22–28، سطر واحد)      │
│ ─────────────────────────── │  اختياري
│ المقارنة (14)                │
└──────────────────────────────┘
  هامش 16، حد 1px، زاوية 12
```

### الخصائص
| الخاصية | النوع | ملاحظة |
|---|---|---|
| `label` | `string` | سطران ثم «…» |
| `value` | `ReactNode` | رقم أو `<PriceDisplay/>`؛ لا يلتف |
| `wrapValue` | `boolean` | لعبارة قصيرة («5 طلب قيد التنفيذ»): تلتف بين الكلمات فقط، متوازنة |
| `icon` | `ReactNode` | `StatIcon`: مربع 48px، زاوية 12، أيقونة 24px |
| `badge` | `ReactNode` | `StatBadge`: 14px، زاوية 6، ألوان: نجاح/خطر/محايد/معلومة |
| `footer` | `ReactNode` | سطر المقارنة، 14px، يلتف |
| `onClick` | `() => void` | يجعل البطاقة زراً (`<button type="button">`) |

### الحالات
| الحالة | السلوك |
|---|---|
| مرور الماوس (قابلة للضغط) | حد أغمق وخلفية رمادية خفيفة، 200ms، بلا حركة مع `prefers-reduced-motion` |
| التركيز | حلقة التركيز الافتراضية للزر |
| رقم طويل جداً | يصغر حتى 22px بعرض البطاقة؛ البطاقة أعرض من 200px دائماً في `AutoGrid` |

### RTL
النسبة المئوية الموقّعة («-66.7%») تُعرض من اليسار لليمين (`dir="ltr"`) حتى لا تنقلب إشارتها؛ النص العربي في الشارة يبقى بالاتجاه العام.
