# الجهات التي تعالج بيانات لسين

`seen-sentry-setup-task.md` (البند 7.3). آخر تحديث: 25 نوفمبر 2026.

القائمة من الكود: كل خدمة خارجية يتصل بها التطبيق أو الخادم.

- **«يؤكده المؤسس»** = قيمة تعتمد على إعدادات الحساب أو العقد، لا يكشفها الكود.
- **أساس النقل خارج المملكة:** اتفاقية معالجة البيانات (DPA) مع الجهة، أو عقد الخدمة نفسه.
