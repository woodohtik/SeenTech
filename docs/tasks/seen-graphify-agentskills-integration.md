# دمج Graphify + Agent Skills الرسمية من Anthropic

فحصت الاثنتين فعليًا (استنساخ وقراءة الكود، لا اعتمادًا على الوصف التسويقي فقط) قبل التوصية بهما.

---

## 1️⃣ Graphify — يحوّل مشروعك لرسم معرفي قابل للاستعلام

### لماذا مفيدة تحديدًا لمشروع "سِين"
مشروعك أصبح كبيرًا ومتشابك الروابط فعليًا (migrations ↔ services ↔ components ↔ push notifications ↔ vertical config) — عدة مرات في هذه المحادثة احتجت تتبّع علاقات بين ملفات عبر grep يدوي متكرر لأفهم من يستدعي من. Graphify يبني هذا كرسم بياني مرة، ويُستعلَم منه بدل تكرار البحث اليدوي في كل جلسة جديدة.

### فحص الأمان (فعلي، لا نقلًا عن الوصف)
استنسخت الكود وفحصته: مشروع ناضج فعليًا (`ARCHITECTURE.md`, `SECURITY.md`, `BENCHMARKS.md`, سجل تغييرات ضخم يعكس تطويرًا حقيقيًا طويل المدى، اختبارات مخصَّصة لسلامة الـ git hooks نفسها). لا نمط `curl | bash`، لا `eval`، لا `os.system` مريب. الفحص المحلي للكود (AST عبر tree-sitter) **لا يغادر جهازك إطلاقًا** — فقط تحليل الوثائق/PDF/الصور (اختياري) يحتاج مفتاح API لموديل تختاره أنت، أو Ollama محليًا بلا أي اتصال خارجي إطلاقًا.

⚠️ ملاحظة أمانة: الأداة من شركة حديثة جدًا (YC S26 — أُسِّست قبل أشهر قليلة فقط) رغم أن الرقم المعروض للنجوم على GitHub كبير جدًا لعمر بهذا القِصر — لا أستطيع التحقق من صحة هذا الرقم بنفسي، لكن هذا لا يغيّر تقييم الكود نفسه الذي فحصته وهو نظيف وجاد.

### التثبيت (جلسة Claude Code العادية على جهازك — يحتاج إنترنت + `uv`)
```bash
uv tool install graphifyy
graphify install
```
ثم داخل `D:\seen-repo`، في Claude Code:
```
/graphify .
```
ابدأ بدون ربط أي مفتاح API خارجي (تحليل الكود نفسه لا يحتاجه) — أضِف مفتاحًا لاحقًا فقط إن أردت تحليل ملفات SQL/PDF/التوثيق ضمن الرسم أيضًا.

## 2️⃣ Agent Skills — المستودع الرسمي من Anthropic نفسها

هذا مصدر رسمي 100% — لا حاجة لفحص أمان إضافي (هو المصدر الذي أُنشئ منه نظام المهارات نفسه). يحتوي حزمتين:

### `example-skills` — الأهم لمشروعك
```
/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
```
أهم ما فيها لمشروعك تحديدًا:
- **`webapp-testing`** — اختبار وتصحيح تفاعلي لتطبيق ويب محلي عبر Playwright (يشغّل السيرفر، يلتقط لقطات شاشة، يقرأ سجلات المتصفح). **ملاحظة مهمة**: هذه مختلفة عن `qa-skills` (Playwright) المثبَّتة/الموصى بها سابقًا — تلك لتوليد حزمة اختبارات E2E دائمة لـCI، وهذه لتصحيح تفاعلي سريع أثناء التطوير نفسه. لا تعارض، تُستخدَمان معًا لأغراض مختلفة.
- `mcp-builder` — إن احتجت مستقبلاً بناء خادم MCP مخصَّص لمشروعك.
- `skill-creator` — لبناء مهارات مستقبلية خاصة بمشروع سِين نفسه بدل الاعتماد على مهارات مجتمعية فقط.

### `document-skills` — أولوية أقل لهذا المشروع تحديدًا
```
/plugin install document-skills@anthropic-agent-skills
```
تشمل docx/pdf/pptx/xlsx — مفيدة لو احتجت توليد تقارير/مستندات عن المشروع نفسه لاحقًا، لا علاقة مباشرة بكود "سِين" التشغيلي. ثبّتها فقط إن احتجتها فعلاً.
