# دمج BMAD-METHOD — "فريق التطوير الكامل" في مشروع سِين

## ما هي، ولماذا هذه تحديدًا

بحثت عن "مهارة فيها فريق تطوير كامل" واستنسخت المرشّح الأقوى وفحصت كوده فعليًا قبل التوصية به (لا تكرارًا لخطأ ECC السابق): **BMAD-METHOD** (`bmad-code-org/BMAD-METHOD`).

**لماذا وثقت فيها بخلاف ECC المرفوضة سابقًا**: 52.7 ألف نجمة و6 آلاف fork بأرقام واقعية ومنطقية (لا 246 ألف بصيانة شخص واحد)، مؤلف حقيقي معروف (Brian "BMad" Madison)، مرخّصة MIT، بنية مشروع ناضجة فعليًا (CI، اختبارات، `SECURITY.md`، `CONTRIBUTORS.md`، توثيق بـ4 لغات). فحصت سكربتات التثبيت والمهارات بحثًا عن أنماط خطرة (تنزيل وتنفيذ كود عن بُعد، تسريب بيانات لتحليلات خارجية، مسارات مكتوبة يدويًا) — **لا شيء مريب**.

## ما الذي تحصل عليه فعليًا (فحصت `.claude-plugin/plugin.json`)

**5 وكلاء بأدوار حقيقية** (هذا هو "الفريق"):
- `bmad-agent-analyst` — محلل
- `bmad-agent-pm` — مدير منتج
- `bmad-agent-architect` — مهندس معماري
- `bmad-agent-ux-designer` — مصمّم UX
- `bmad-agent-dev` — مطوّر

بالإضافة لمهارات مرحلية كاملة: **التخطيط** (`bmad-prd`, `bmad-create-epics-and-stories`, `bmad-sprint-planning`, `bmad-architecture`, `bmad-ux`, `bmad-project-context`)، **التنفيذ** (`bmad-build`, `bmad-code-review`, `bmad-qa-generate-e2e-tests`, `bmad-retrospective`)، وأدوات تفكير (`bmad-brainstorming`, `bmad-deep-recon`, `bmad-party-mode` — نقاش جماعي بين الوكلاء).

## التثبيت (من جلسة Claude Code العادية على جهازك — يحتاج إنترنت فعليًا)

**المتطلبات أولاً** (تحقّق قبل البدء):
- Node.js ≥ 20.12
- Python ≥ 3.10
- أداة `uv` (`pip install uv` إن لم تكن مثبَّتة)

```bash
cd D:\seen-repo
npx bmad-method install
```
سيسألك المثبِّت تفاعليًا عن الوحدات المطلوبة — اختر `bmad-method-analyze-plan-build` (الوحدة الوحيدة الموجودة حاليًا، تغطي كل الأدوار أعلاه).

## ⚠️ نقطة مهمة: التداخل مع Superpowers المثبَّتة عندك أصلاً

كلا الإطارين يملك مهارة `brainstorming` ومهارات تخطيط. لتفادي التباس أيهما يستجيب لأي طلب، اعتمد هذا التقسيم عند الاستخدام:

| المستوى | استخدم |
|---|---|
| تخطيط منتج/ميزة جديدة من الصفر (PRD، تقسيم لـ epics وsprints، قرار معماري) | **BMAD** (`bmad-agent-pm`, `bmad-agent-architect`) |
| تنفيذ فعلي لمهمة محدَّدة داخل الكود (اختبار أولاً، تصحيح منهجي، تحقّق قبل الإغلاق) | **Superpowers** (كما في كل مهام التنفيذ السابقة) |

مثال عملي على مشروعك الحالي: استخدم `bmad-agent-pm` + `bmad-prd` لتحويل فكرة "بطاقة المشاركة عند التسليم" (المرحلة المؤجَّلة في `seen-customer-app-design-upgrade-task.md`) إلى PRD وepics حقيقية بدل ملف مهمة عربي أكتبه أنا يدويًا — ثم نفّذها بانضباط Superpowers كالمعتاد.
