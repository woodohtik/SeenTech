# محتوى مدونة سِين

ملف `.md` واحد لكل مقالة في هذا المجلد. الرابط (`slug`) = اسم الملف بلا الامتداد
(أحرف عربية مباحة، بلا تحويل للاتينية).

## الترويسة (frontmatter)

```yaml
---
title: "عنوان المقالة"
meta_description: "وصف قصير يظهر في نتائج البحث وبطاقات المشاركة."
cluster: orders   # أحد القيم الثمانية أدناه فقط
publish_date: "2026-11-03"
related:            # حتى 3 روابط slug لمقالات أخرى، اختياري
  - "slug-مقالة-أخرى"
---
```

### المحاور الثمانية الثابتة (`cluster`)

`management`، `orders`، `measurements`، `software`، `season`، `e-invoicing`، `womens`، `curtains`.
أي قيمة غير هذه تُوقِف البناء بخطأ يسمّي الملف.

## جسم المقالة (Markdown)

- أول فقرة تبدأ بـ«**الجواب المختصر:**» → صندوق منفصل فوق المقالة.
- كل `##` → قسم، يدخل في الفهرس.
- `## وين تدخل منصة سين؟` → الصندوق الكحلي مع زر «نوريك إياه في محلك» (ثابت، لا يتغيّر).
- `> **عن منصة سين:**` → صندوق منفصل.
- `## أسئلة شائعة` و`###` تحتها → أكورديون الأسئلة + JSON-LD من نوع FAQPage.
- `## اقرأ بعد` → عنوان قسم فقط؛ الكروت نفسها من حقل `related` بالترويسة.
- أي `## نموذج ...` → إطار منقّط + زر «اطبع النموذج».
- سطر «تحرير: ...» → يُحذَف من الجسم ويظهر في البيانات الوصفية تحت العنوان بدلاً منه.

مدة القراءة تُحسَب تلقائياً (عدد الكلمات ÷ 180، بحد أدنى دقيقتين) — لا حاجة لكتابتها.
