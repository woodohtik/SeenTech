# وسيط سين للطباعة — SEEN Print Agent

برنامج صغير يعمل على **جهاز الكاشير** ويجعل نظام سين يطبع الفواتير **فوراً وبدون أي مربع حوار**، باستخدام تعريف الطابعة الرسمي المثبّت في ويندوز.

يعمل من **ويندوز ومن الأندرويد معاً**: تابلت الكاشير يطبع على طابعة موصولة بكمبيوتر المتجر بدون تنصيب أي شيء على التابلت.

---

## لماذا تغيّر التصميم في الإصدار 2؟

الإصدار 1 كان يفتح خادماً محلياً على `http://127.0.0.1:9110` وينتظر المتصفح. **هذا التصميم توقّف عن العمل** — وكانت النتيجة رسالة مضلِّلة: «الوسيط غير مُشغَّل» بينما الوسيط يعمل فعلاً.

| السبب | التفصيل |
|---|---|
| **Local Network Access** | Chrome (M130+) يمنع أي صفحة على الإنترنت من مخاطبة `127.0.0.1` أو الشبكة المحلية إلا بإذن صريح. ترويسة `Access-Control-Allow-Private-Network` القديمة لم تعد كافية. الـ `fetch` يفشل بـ `TypeError: Failed to fetch` — وهو نفس شكل خطأ «المنفذ مغلق»، فلا يستطيع الكود التمييز بينهما. |
| **Mixed Content** | Firefox و Safari يحجبان `https://` ← `http://127.0.0.1` حجباً كاملاً. |
| **الأندرويد** | لا يوجد وسيط محلي على الأندرويد إطلاقاً، فلم يكن هناك أي مسار للطباعة الصامتة من التابلت. |

**الحل: قلب اتجاه الاتصال.** الوسيط هو الذي يتصل خارجاً بسيرفر سين وينتظر المهام:

```
[متصفح أي جهاز]  ──POST──►  [سيرفر سين]  ◄──long-poll──  [وسيط الكاشير]
                                                                 │
                                                                 ▼
                                                    سبولر ويندوز / TCP 9100
```

لا يوجد أي اتصال بـ `localhost` ⇒ **لا mixed content، لا CORS، لا Local Network Access، ولا حاجة لفتح أي منفذ في جدار الحماية.**

---

## المتطلبات

- **ويندوز 7 أو أحدث.** لا شيء غير ذلك.
- **لا يحتاج Node.js.** PowerShell مثبّت مسبقاً في كل نسخ ويندوز.
- **لا يحتاج صلاحيات مسؤول.**
- الطابعة مثبّتة في ويندوز وتطبع صفحة اختبار من إعدادات ويندوز.

يعمل أيضاً على ماك ولينكس عبر CUPS (بنسخة Node.js).

---

## التشغيل

1. انسخ مجلد `print-agent` إلى جهاز الكاشير — يُفضّل مكاناً دائماً مثل `C:\SeenPrintAgent`.
2. اضغط مزدوجاً على **`تشغيل-وسيط-الطباعة.bat`**.
3. عند أول تشغيل سيسألك عن رابط نظام سين. أدخله (مثل `https://app.seen.sa`) ثم Enter. يُحفظ الرابط فلا يُسأل مرة أخرى.
4. ستظهر نافذة تعرض **رمز اقتران من 6 أحرف** وقائمة طابعاتك. **اتركها مفتوحة أثناء العمل.**

```
  ╔══════════════════════════════════════════════════════════╗
  ║           وسيط سين للطباعة  —  SEEN Print Agent          ║
  ╚══════════════════════════════════════════════════════════╝

  الطابعات المثبتة (2):
    • XP-80C   [افتراضية]
    • Microsoft Print to PDF   [وهمية]

  ┌────────────────────────────────────────────────────────┐
  │  رمز الاقتران — أدخله في: إعدادات الطابعة ← اقتران     │
  │                                                        │
  │                    K7M2QX                              │
  └────────────────────────────────────────────────────────┘

  ✅ الوسيط متصل وينتظر مهام الطباعة.
```

### التشغيل التلقائي مع ويندوز

اضغط مزدوجاً على **`تنصيب-تشغيل-تلقائي.bat`** وأدخل رابط النظام. سيعمل الوسيط تلقائياً عند كل تسجيل دخول، بنافذة مخفية.

> انقل المجلد لمكانه الدائم **قبل** التنصيب، لأن المهمة المجدولة تشير للمسار الحالي.

للإلغاء:

```powershell
.\seen-print-agent.ps1 -Uninstall
```

## الربط مع نظام سين

1. افتح نظام سين ← **إعدادات الطابعة**.
2. في بطاقة **«الطباعة الصامتة (بدون مربع حوار)»** بالأعلى، أدخل رمز الاقتران واضغط **اقتران**.
3. ستظهر طابعات جهاز الكاشير — اضغط **«ربط للطباعة الصامتة»** بجوار طابعتك الحرارية.
4. اضغط **اختبار**. يجب أن يخرج إيصالان بدون أي نقرة: إيصال اتصال بالإنجليزية، وفاتورة عربية.

**الاقتران يبقى محفوظاً** — لا تحتاج تكراره كل يوم. يحتاج إعادة فقط إذا أُعيد تشغيل السيرفر (سيظهر رمز جديد في نافذة الوسيط).

### من جهاز أندرويد

لا تنصّب أي شيء على التابلت. شغّل الوسيط على كمبيوتر المتجر، وأدخل **نفس رمز الاقتران** في إعدادات الطابعة على التابلت. ستُطبع الفواتير على طابعة المتجر.

## الخيارات

```powershell
.\seen-print-agent.ps1 -ServerUrl https://app.seen.sa -Printer "XP-80C"
```

| الخيار | الوصف |
|---|---|
| `-ServerUrl <url>` | رابط نظام سين. إلزامي أول مرة فقط، ثم يُحفظ. |
| `-Printer "<name>"` | الطابعة الافتراضية للوسيط عند عدم تحديد طابعة في المهمة. |
| `-Install` | تنصيب التشغيل التلقائي مع ويندوز. |
| `-Uninstall` | إزالة التشغيل التلقائي. |
| `-Quiet` | بدون واجهة — للتشغيل في الخلفية. |

الإعدادات والسجل يُحفظان في `%LOCALAPPDATA%\SeenPrintAgent\`.

## بناء ملف EXE مستقل (للمطوّر)

إن أردت توزيع ملف تنفيذي واحد بدل سكربت PowerShell:

```powershell
.\build-exe.ps1
```

يحتاج **Node.js 22+** على جهاز البناء فقط. الناتج `dist\seen-print-agent.exe` لا يحتاج Node.js على جهاز العميل.

> **مستحسن:** وقّع الملف بشهادة Code Signing، وإلا سيعرض SmartScreen تحذير «تطبيق غير معروف». التفاصيل في أعلى `build-exe.ps1`.

نسخة PowerShell كافية تماماً وظيفياً — ملف EXE أفضل فقط للتوزيع الواسع.

## الأمان

- الوسيط **لا يفتح أي منفذ** ولا يستمع على الشبكة. كل اتصالاته صادرة نحو سيرفرك فقط.
- كل محطة لها `agentToken` سري يُصدره السيرفر، ومطلوب في كل طلب.
- إرسال مهمة طباعة يتطلب `clientToken` لا يُمنح إلا بعد إدخال رمز الاقتران الصحيح.
- رموز الاقتران من أبجدية بلا حروف متشابهة (لا `0/O` ولا `1/I/L`)، ومحاولات التخمين محدودة بـ 10 في الدقيقة لكل عنوان IP.
- الوسيط لا يقرأ ولا يخزّن بيانات الفواتير — يستقبل بايتات ويمرّرها للطابعة.

---

## ⚠️ ملاحظة نشر مهمة

طابور المهام في السيرفر **مخزَّن في الذاكرة**، وطلبات الانتظار (long-poll) تحتاج عملية طويلة العمر. هذا يناسب نمط تشغيل هذا المشروع:

```bash
npm start   # node dist/server.cjs → app.listen
```

**لا يعمل على Vercel Serverless Functions** (كل طلب في نسخة منفصلة، ومهلة التنفيذ قصيرة). إن نشرت الواجهة على Vercel فيجب أن يعمل `server.ts` على مستضيف يدعم العمليات الطويلة — مثل Railway أو Render أو Fly.io أو VPS — وأن يشير رابط الوسيط لذلك المستضيف.

للنشر على بيئة serverless متعددة النسخ، استبدل مخزن `stations`/`jobs` في `src/server/printRelay.ts` بجدولين في Supabase، وحوّل `/agent/poll` إلى استقصاء قصير. الواجهة معزولة لهذا الغرض.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| «رمز اقتران غير صحيح» | تأكد أن نافذة الوسيط مفتوحة وأن الرمز مطابق. الرمز يتغيّر إذا أُعيد تشغيل السيرفر. |
| «الوسيط غير متصل» في النظام | نافذة الوسيط مغلقة، أو جهاز الكاشير غير متصل بالإنترنت، أو رابط السيرفر خطأ. راجع `%LOCALAPPDATA%\SeenPrintAgent\agent.log`. |
| «اسم الطابعة غير موجود في ويندوز» | تغيّر اسم الطابعة. اضغط «تحديث» في إعدادات الطابعة وأعد الربط. |
| «تم رفض الوصول للطابعة» (رمز 5) | شغّل الوسيط بنفس حساب المستخدم الذي ثبّت الطابعة. |
| «الطابعة مشغولة أو الطابور متوقف» (رمز 63) | افتح طابور الطباعة في ويندوز وامسح المهام المعلّقة. |
| يخرج ورق فارغ أو رموز غريبة | الطابعة ليست ESC/POS حرارية، أو حجم الورق خطأ. غيّره إلى `80mm` أو `58mm` في إعدادات الطابعة. |
| الطابعة A4 لا تطبع صامتاً | أوامر ESC/POS للطابعات الحرارية فقط. للورق العادي استخدم «طابعة النظام». |
| لا توجد طابعات في القائمة | ثبّت تعريف الطابعة في ويندوز وتأكد أنها تطبع صفحة اختبار من إعدادات ويندوز. |
| PowerShell يرفض تشغيل السكربت | ملف الـ `bat` يمرر `-ExecutionPolicy Bypass` تلقائياً. إن شغّلت `.ps1` مباشرة أضف الخيار بنفسك. |

## واجهة السيرفر البرمجية

للمطوّرين — المسارات معرّفة في `src/server/printRelay.ts`:

| المسار | الجهة | الوصف |
|---|---|---|
| `POST /api/print/agent/hello` | الوسيط | تسجيل المحطة، يُرجع `stationId` و `agentToken` و `pairCode` |
| `GET /api/print/agent/poll` | الوسيط | انتظار مهمة (long-poll، 25 ثانية) — يعمل أيضاً كنبضة حياة |
| `POST /api/print/agent/result` | الوسيط | إبلاغ نتيجة المهمة |
| `POST /api/print/pair` | المتصفح | `{ pairCode }` → `{ stationId, clientToken }` |
| `GET /api/print/station/:id` | المتصفح | حالة المحطة وقائمة طابعاتها |
| `POST /api/print/job` | المتصفح | إضافة مهمة للطابور، يُرجع `jobId` |
| `GET /api/print/job/:id` | المتصفح | متابعة حالة المهمة |
| `POST /api/print/raw` | المتصفح | طابعة شبكة مباشرة (يشترط أن يكون السيرفر على شبكة الطابعة) |
| `POST /api/print/probe` | المتصفح | فحص اتصال طابعة شبكة |

مسارات الوسيط تحتاج ترويسة `Authorization: Bearer <agentToken>`.
